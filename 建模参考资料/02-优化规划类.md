# 02 · 优化规划类模型

> 适用题型：优化类（生产计划、资源分配、选址、调度、路径）。核心链路：
> **决策变量 → 目标函数 → 约束条件 → 求解 → 可行性校验 → 灵敏度分析**。
>
> 求解纪律：先保证可行解，再谈最优；报告里必须写清求解器状态与约束违反量。

## 1. 线性规划（LP）

- **定位**：目标与约束全为线性的最基础优化模型。
- **场景**：生产计划、配料、运输、投资组合（均值-方差简化版）。
- **边界**：
  - 变量必须连续、目标与约束线性；
  - 最优解一定在多面体顶点（单纯形理论），解空间无界时要检查业务边界；
  - "整数"需求要换整数规划，四舍五入连续解常常不可行。
- **数据形态**：`c`，`(n,)` 目标系数；`A_ub/b_ub`，`(m_ub, n)/(m_ub,)` 不等式 `Ax ≤ b`；`A_eq/b_eq` 等式约束；`bounds`，`[(lb, ub), ...]`。
- **关键调用**：

```python
import program as pm

r = pm.optimize.solve_lp(c=[3, 5], A_ub=[[1, 0], [0, 2], [3, 2]], b_ub=[4, 12, 18],
                         bounds=[(0, None)] * 2, maximize=True)
r.fun, r.x, r.success                    # 目标值 / 最优解 / 求解状态

# 等价底层调用（scipy）
from scipy.optimize import linprog
res = linprog(c=[-3, -5], A_ub=..., b_ub=..., method="highs")   # 最小化，最大化需取负
```

## 2. 整数规划 / 0-1 规划（ILP）

- **定位**：变量取值必须为整数或 0-1，用于"选/不选""建/不建""台数"。
- **场景**：选址（0-1）、背包、生产批量、任务分配、排班。
- **边界**：
  - NP-hard，规模大时求解慢——先尝试 LP 松弛看差距（gap）；
  - 不能用连续解简单取整；
  - 目标"数量最多"等需要大 M 法线性化（见第 6 条）。
- **数据形态**：同 LP；关键是把业务语言翻译成变量：`x_i ∈ {0,1}`、`y_j ∈ Z≥0`。
- **关键调用**：

```python
# 方式一：program 封装（推荐）
r = pm.optimize.solve_lp(c, A_ub, b_ub, integer=[1, 1], maximize=True)   # 逐变量：1=整数
r = pm.optimize.solve_lp(c, A_ub, b_ub, bounds=[(0, 1)] * n, integer=True)  # 0-1 规划

# 方式二：pulp（建模更直白，支持大 M、逻辑约束）
import pulp
prob = pulp.LpProblem("Plan", pulp.LpMaximize)
x = pulp.LpVariable("x", lowBound=0, cat="Integer")     # 整数
y = pulp.LpVariable("y", cat="Binary")                  # 0-1
prob += 3 * x + 5 * y                                   # 目标函数
prob += x + 2 * y <= 10                                 # 约束
prob.solve(pulp.PULP_CBC_CMD(msg=0))
x.value(), y.value(), pulp.value(prob.objective)
```

## 3. 混合整数规划（MILP）

- **定位**：部分变量整数、部分连续。
- **场景**：选址-分配（0-1 建站 + 连续运量）、机组组合、带固定成本的规划。
- **边界**：模型规模控制（变量数 < 10^4 量级较稳）；固定成本必须用大 M 或"固定费 + 变动费"两段式线性化。
- **数据形态**：连续变量 `x ≥ 0`、整数变量 `y`、大 M 需先估上界（`M = 最大可能量`）。
- **关键调用**：

```python
# 大 M 法：y=1 才允许 x > 0
prob += x <= M * y                  # x 连续产量，y 0-1 开启标志
prob += fixed_cost * y + var_cost * x <= budget
```

## 4. 非线性规划（NLP）

- **定位**：目标或约束含非线性项。
- **场景**：几何优化、非线性拟合约束、物理模型参数、连续设施选址（距离欧氏）。
- **边界**：
  - 只能保证局部最优——**多初值重跑**，或直接用全局方法；
  - 目标非凸时梯度方法易陷局部；约束需按 scipy 格式写；
  - 数值尺度差异大时先做无量纲化。
- **数据形态**：目标函数 `f(x) -> float`；`x0` 初值；`bounds`；约束 `{"type": "ineq", "fun": lambda x: ...}`。
- **关键调用**：

```python
r = pm.optimize.solve_nlp(lambda v: (v[0] - 1) ** 2 + (v[1] - 2) ** 2,
                          x0=[0, 0], bounds=[(-5, 5), (-5, 5)],
                          constraints={"type": "ineq", "fun": lambda v: 3 - v[0] - v[1]})

# 底层：scipy.optimize.minimize(f, x0, method="SLSQP", bounds=..., constraints=...)
```

## 5. 多目标规划

- **定位**：多个互相冲突的目标（成本 vs 质量）。
- **场景**：双目标/三目标权衡、帕累托前沿分析。
- **边界**：
  - "最优"不唯一，要讨论解集（帕累托前沿）而不是单点；
  - 加权和法无法生成非凸前沿的某些段，重要时用 ε-约束法；
  - 权重需说明来源（偏好/量纲归一后主观定）。
- **数据形态**：各目标的系数向量/函数；量纲不同需先归一化。
- **关键调用**：

```python
# 加权和法：扫描权重画帕累托前沿
front = []
for w1 in np.linspace(0, 1, 21):
    r = pm.optimize.solve_lp(c=w1 * c1 + (1 - w1) * c2, A_ub=A_ub, b_ub=b_ub)
    front.append((w1, r.fun))                        # 或记录 (f1, f2) 双目标值

# ε-约束法：把目标 2 写成约束 f2(x) ≤ ε，扫描 ε
r = pm.optimize.solve_nlp(f1, x0, constraints=[{"type": "ineq", "fun": lambda v: eps - f2(v)}])
```

## 6. 整数建模技巧（逻辑线性化）

- **定位**：把"如果…则…""至少选一个"等业务逻辑写成线性约束。
- **场景**：选址开关、互斥项目、阈值触发、成组约束。
- **边界**：大 M 取值不能过大（数值不稳定）也不能过小（误约束）；每个技巧都要在报告中列出。
- **数据形态**：0-1 变量 `y`、量 `x`、上界估计 `M`。
- **关键调用**：

```python
# 1) 大 M：y=1 → x ≥ 100（激活）
prob += x >= 100 * y - M * (1 - y)          # 或 x >= 100 - M*(1-y)
# 2) 互斥：A、B 至多选一个
prob += yA + yB <= 1
# 3) 至少选一个
prob += yA + yB + yC >= 1
# 4) 如果选 A 则必选 B
prob += yA <= yB
# 5) 两段式费用：前 S 单位便宜
prob += cost == c1 * min(x, S) 的线性化（用两个连续变量拆分：x = x1 + x2, x1 ≤ S, x2 ≥ 0）
```

## 7. 动态规划（DP）

- **定位**：多阶段决策，用状态转移递推最优。
- **场景**：资源分配、背包、最短路径、生产-库存、序列对齐。
- **边界**：
  - 需要满足最优子结构与无后效性；
  - 状态维数爆炸（指数级），高维要近似方法；
  - 连续状态需离散化，精度与计算量权衡。
- **数据形态**：状态空间大小与服务集；阶段收益表 `g[i][k]`（第 i 阶段分配 k 资源的收益）。
- **关键调用**：

```python
# 资源分配 DP 核心（n 个项目，总资源 B）
dp = np.zeros(B + 1)
for i in range(n):
    new = dp.copy()
    for b in range(B + 1):
        for k in range(b + 1):
            new[b] = max(new[b], dp[b - k] + g[i][k])
    dp = new
best = dp[B]

# 0-1 背包直接用现成函数
r = pm.optimize.knapsack(values, weights, capacity)     # 整数权重
```

## 8. 运输问题 / 网络流

- **定位**：供需平衡下的最小运费/最大流。
- **场景**：物流调运、管网、任务分派、匹配。
- **边界**：产销不平衡要虚拟产地/销地；最大流要求容量非负；最小费用流注意负圈。
- **数据形态**：供应 `(m,)`、需求 `(n,)`、单位运价 `C`，`(m, n)`。
- **关键调用**：

```python
# 运输问题 = LP（决策变量 x_ij 展平）
# min Σ C_ij x_ij  s.t. 行和=供应, 列和=需求
r = pm.optimize.solve_lp(c=C.ravel(), A_eq=A_eq, b_eq=b_eq, bounds=[(0, None)] * (m * n))

# 最大流（networkx）
import networkx as nx
G = nx.DiGraph()
G.add_edge("s", "a", capacity=10)          # 边带容量
flow_value, flow_dict = nx.maximum_flow(G, "s", "t")
```

## 9. 背包问题（0-1 / 完全）

- **定位**：容量约束下价值最大化。
- **场景**：经费分配、资源装载、投资组合（离散化后）。
- **边界**：权重必须整数化（缩放）；物品数 × 容量过大时 DP 会爆内存，改用分支限界/启发式。
- **数据形态**：`values`，`(n,)`；`weights`，`(n,)` 整数；`capacity` 标量整数。
- **关键调用**：

```python
r = pm.optimize.knapsack([60, 100, 120], [10, 20, 30], capacity=50)
r.best_value, r.items                     # 220, [1, 2]
# 完全背包/多重背包：在 DP 模板中把每件物品的多寡循环改一改即可
```

## 10. 指派问题

- **定位**：n 个人 × n 项任务，一一对应最小成本。
- **场景**：人员排班、任务分配、机器调度。
- **边界**：方阵假设（人数≠任务数补虚拟行列）；成本含负值时仍可用匈牙利算法（会自动处理）。
- **数据形态**：`cost`，`(n, n)` 成本矩阵（最大化时传收益矩阵）。
- **关键调用**：

```python
a = pm.optimize.assignment([[4, 1, 3], [2, 0, 5], [3, 2, 2]])
a.pairs(), a.total                        # [(0,1),(1,0),(2,2)], 5

# 底层：scipy.optimize.linear_sum_assignment(cost)
```

## 11. 旅行商问题（TSP）

- **定位**：访问所有点各一次并回到起点的最短环。
- **场景**：配送路线、巡检路径、钻孔路径。
- **边界**：
  - 精确求解（如 Held-Karp DP）只能到 ~20 个点；
  - 大规模用启发式（最近邻 + 2-opt/遗传/蚁群），不保证最优但要报差距；
  - 考虑实际约束（时间窗、车辆数）时要升级为 VRP 模型。
- **数据形态**：坐标 `(n, 2)` 或直接距离矩阵 `(n, n)`。
- **关键调用**：

```python
d = pm.optimize.distance_matrix(points)             # 坐标 → 距离矩阵
tour, length = pm.optimize.tsp_2opt(d)              # 最近邻构造 + 2-opt 改进
# 精确解（小规模）：Held-Karp DP 或 pulp 的 MTZ 模型
```

## 12. 典型建模配方（背下来直接用）

| 题型 | 决策变量 | 目标 | 典型约束 |
| --- | --- | --- | --- |
| 生产计划 | 各产品产量 `x_j ≥ 0` | max 利润 | 资源上限、需求上下限 |
| 选址 | `y_i ∈ {0,1}` 建站；`x_ij` 运量 | min 固定费+运输费 | 需求满足、容量、`x_ij ≤ M y_i` |
| 排班 | `x_{ij} ∈ {0,1}` 第 i 人第 j 班 | min 人力/成本 | 每班需求、每人班次上限、连续班限制 |
| 投资组合 | `x_i` 投资额 | max 收益（或 min 风险） | 预算、单资产上限、风险 VaR 约束 |
| 调度 | `x_{ij}` 顺序 0-1 | min 完工时间 | 工序先后、机器不冲突 |
| 下料 | 切割方案次数 `x_k` 整数 | min 原料根数 | 各零件需求满足 |

## 13. 遗传算法（GA）

- **定位**：模拟自然选择的通用随机搜索，适合复杂非线性/离散空间。
- **场景**：目标不可导、解空间离散、约束复杂、精确算法不可行。
- **边界**：
  - 不保证最优，只能给"满意解"；需要报收敛曲线；
  - 参数（种群、交叉率、变异率）敏感——固定随机种子并做参数说明；
  - 小规模问题别用 GA（显得杀鸡用牛刀）。
- **数据形态**：目标函数 `f(个体向量) -> float`；编码（实数/二进制/排列）；边界 `bounds`。
- **关键调用**：

```python
# 直接用差分进化（scipy 内置，稳定省事，固定 seed）
r = pm.optimize.global_minimize(f, bounds=[(0, 10)] * 5, seed=42, maxiter=300, popsize=40)

# 需要"教科书式 GA"时手写核心：
pop = np.random.uniform(lb, ub, (pop_size, dim))
for gen in range(max_gen):
    fit = np.array([f(ind) for ind in pop])
    elite = pop[np.argsort(fit)[:n_elite]]                  # 选择
    children = crossover(elite, rng)                        # 交叉
    children = mutate(children, rng)                        # 变异
    pop = np.vstack([elite, children])
```

## 14. 模拟退火（SA）

- **定位**：以一定概率接受劣解跳出局部最优。
- **场景**：组合优化（TSP、排班、布局）、连续函数多峰。
- **边界**：降温计划（初温、速率）影响大；终止条件需明确；多次重启动更稳。
- **数据形态**：当前解 `x`、邻域生成函数 `neighbor(x)`、目标 `f`。
- **关键调用**：

```python
x, best = x0, x0
for k in range(max_iter):
    T = T0 * (T_end / T0) ** (k / max_iter)                      # 指数降温
    x_new = x + rng.normal(0, sigma)                             # 邻域
    if f(x_new) < f(x) or rng.random() < np.exp(-(f(x_new) - f(x)) / T):
        x = x_new
    if f(x) < f(best):
        best = x
```

## 15. 粒子群（PSO）

- **定位**：群体协作搜索连续空间。
- **场景**：连续参数优化、神经网络调参、函数极值。
- **边界**：连续型算法（离散问题要改编码）；易早熟收敛，常配变异或重启；同样要固定种子。
- **数据形态**：`f(x)`、`bounds`、粒子数/迭代数。
- **关键调用**：

```python
X = rng.uniform(lb, ub, (n_particles, dim))
V = np.zeros_like(X)
pbest = X.copy()
gbest = X[np.argmin([f(x) for x in X])]
for it in range(max_iter):
    r1, r2 = rng.random((n_particles, 1)), rng.random((n_particles, 1))
    V = w * V + c1 * r1 * (pbest - X) + c2 * r2 * (gbest - X)     # 速度更新
    X = np.clip(X + V, lb, ub)                                    # 位置更新 + 边界
    fits = np.array([f(x) for x in X])
    pbest = np.where((fits < [f(p) for p in pbest])[:, None], X, pbest)
    gbest = pbest[np.argmin([f(p) for p in pbest])]
```

## 16. 灵敏度分析（所有优化题的必做项）

- **定位**：检验结论对参数扰动的稳健性。
- **场景**：目标/约束关键系数 ±5%~±20%，看最优解与目标值变化。
- **边界**：一次只扰动少数关键参数（避免组合爆炸）；说明选择哪些参数及理由。
- **数据形态**：参数清单 + 扰动幅度网格。
- **关键调用**：

```python
rows = []
for delta in (-0.2, -0.1, 0.0, 0.1, 0.2):
    r = pm.optimize.solve_lp(c=c, A_ub=A_ub, b_ub=b_ub * (1 + delta), maximize=True)
    rows.append({"扰动": f"{delta:+.0%}", "目标值": r.fun})
# 再画折线图 + 写报告
```

!!! tip "优化类论文的证据链"
    `模型假设 → 变量与约束表 → 求解状态 → 可行解 → 最优解 → 约束校验 → 灵敏度 → 结论`。
    缺任何一环都容易被扣分，尤其是**约束校验**和**灵敏度**。
