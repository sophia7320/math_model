# 04 · 分类聚类与统计分析

> 适用题型：数据分析类、分类/识别类、聚类分群类、因素分析类。
> 两条主线：**先统计找规律（相关/检验/回归），再用机器学习分群或判别**。

---

## A. 统计检验与方法

### 1. 检验方法选择速查

| 数据类型 | 目的 | 方法 | 调用 |
| --- | --- | --- | --- |
| 单组连续 | 与常数比较 | 单样本 t / Wilcoxon | `pm.stats.t_test_one(x, mu)` |
| 两组连续 | 均值差异 | Welch t / Mann-Whitney | `pm.stats.t_test_ind(a, b)` |
| 配对连续 | 前后差异 | 配对 t / 符号秩 | `pm.stats.t_test_paired(a, b)` |
| 多组连续 | 均值差异 | ANOVA / Kruskal | `pm.stats.compare_groups(*groups)` |
| 两分类 | 独立性 | 卡方 / Fisher | `pm.stats.chi2_test(table)` |
| 连续 vs 连续 | 相关 | Pearson / Spearman | `pm.stats.corr_test(x, y)` |
| 变量分布 | 正态性 | Shapiro-Wilk | `pm.stats.normality(x)` |

- **边界**：参数方法要求近似正态/方差齐性（本库 `compare_groups` 会自动切换）；
  小样本（n<30）优先非参数；p 值只是证据强度，还要报告效应量（Cohen's d 已含在结果里）。
- **数据形态**：各组为 1D 数值序列；卡方输入列联表 `(r, c)`。
- **关键调用**：

```python
r = pm.stats.t_test_ind(group_a, group_b)
print(r)                                    # 中文结论 + p 值 + Cohen's d
print(r.to_dict())                          # 也可以转成表写进报告
```

### 2. 相关分析（找影响因素）

- **定位**：量化变量间线性/单调关系，筛特征、画相关矩阵。
- **场景**：因素分析、指标筛选、共线性初筛。
- **边界**：相关 ≠ 因果；Pearson 只测线性；异常值会严重拉偏（看散点图确认）。
- **数据形态**：数值 DataFrame `(n, p)`，最好先处理缺失与异常。
- **关键调用**：

```python
rho = pm.stats.corr_test(x, y, method="pearson")      # 单个：r, p 值
C = pm.stats.corr_matrix(df, method="spearman")       # 矩阵
pm.corr_heatmap(df, method="pearson", save="corr")    # 出图（含 -1~1 色阶）
```

---

### 3. 回归诊断（做完回归别急着交）

- **定位**：检查线性回归的假设是否成立。
- **场景**：所有使用了 OLS 的题目。
- **边界**：诊断发现违背后要么换方法（稳健回归/非参数），要么在论文中如实说明局限。
- **数据形态**：回归残差、设计矩阵 `(n, p)`。
- **关键调用**：

```python
model = pm.stats.ols(df, y="y", xs=["x1", "x2"])
resid = model.resid
pm.scatter(model.fittedvalues, resid, xlabel="拟合值", ylabel="残差", save="resid_plot")  # 异方差/非线性

# 多重共线性 VIF（> 10 视为严重）
from statsmodels.stats.outliers_influence import variance_inflation_factor
from statsmodels.tools import add_constant
Xc = add_constant(df[["x1", "x2"]])
vif = [variance_inflation_factor(Xc.values, i) for i in range(Xc.shape[1])]
```

## B. 分类判别类

### 4. 逻辑回归

- **定位**：输出概率的解释型分类器。
- **场景**：二分类风险/违约/发病预测；需要解释 OR（优势比）。
- **边界**：线性决策边界；类别不均衡要调 `class_weight`；多重共线性影响系数解释。
- **数据形态**：`X`，`(n, p)` 标准化；`y`，`(n,)` 取值 {0, 1}。
- **关键调用**：

```python
res = pm.ml.fit_classifier("logreg", X, y, seed=42)
res.y_proba[:, 1]                                     # 正类概率
res.model.named_steps["logisticregression"].coef_     # 系数（如用管道）
```

---

### 5. 判别分析（LDA / QDA）

- **定位**：基于类内/类间散布的经典统计判别。
- **场景**：样本量不大、近似正态、类别可分性检验；可同时降维（LDA 最多到 `K-1` 维）。
- **边界**：LDA 假设各类协方差相同（QDA 放宽但参数更多）；强非线性无效；对异常值敏感。
- **数据形态**：`X`，`(n, p)` 连续；`y` 类别标签（≥2 类）。
- **关键调用**：

```python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis as LDA
lda = LDA().fit(X, y)
lda.score(X, y); lda.transform(X)[:, :2]              # 分类精度 / 降维可视化
```

---

### 6. KNN（K 近邻）

- **定位**：无参数、直觉简单的分类/回归。
- **场景**：小样本基线、特征空间局部结构明显。
- **边界**：必须标准化；维数灾难（>20 维效果差）；预测阶段计算量大；k 需交叉验证选。
- **数据形态**：`X` 标准化 `(n, p)`；`y` 标签。
- **关键调用**：

```python
from sklearn.neighbors import KNeighborsClassifier
knn = KNeighborsClassifier(n_neighbors=5).fit(Xs, y)
# program 快捷（自动标准化）
res = pm.ml.fit_classifier("knn", X, y, seed=42)
```

---

### 7. SVM（支持向量机）

- **定位**：最大间隔分类，小样本高维强。
- **场景**：中小样本、维度高、边界复杂（RBF 核）。
- **边界**：需标准化；`C/gamma` 敏感需网格搜索；概率输出需 `probability=True`（较慢）。
- **数据形态**：`X` 标准化 `(n, p)`；`y` ±1 或 {0,1}。
- **关键调用**：

```python
from sklearn.model_selection import GridSearchCV
from sklearn.svm import SVC
gs = GridSearchCV(SVC(), {"C": [0.1, 1, 10], "gamma": ["scale", 0.1]}, cv=5).fit(Xs, y)
gs.best_params_; gs.best_estimator_.score(Xs, y)
```

---

### 8. 决策树 / 随机森林 / GBDT

- **定位**：可解释规则（单树）与高精度集成（森林/提升）。
- **场景**：混合类型特征、需要特征重要性、非线性。
- **边界**：单树易过拟合（限制深度/剪枝）；集成树不擅外推；解释重要性时注意基数偏差。
- **数据形态**：`X`，`(n, p)` 数值或编码类别；`y` 标签。
- **关键调用**：

```python
from sklearn.tree import DecisionTreeClassifier, export_text
tree = DecisionTreeClassifier(max_depth=4, random_state=0).fit(X, y)
print(export_text(tree, feature_names=names))         # 可读规则

res = pm.ml.fit_classifier("rf", X, y, seed=42)       # 集成
res.model.feature_importances_
```

---

### 9. 朴素贝叶斯

- **定位**：概率分类基线，速度极快。
- **场景**：文本/垃圾识别、小样本多类别、在线预测。
- **边界**：特征条件独立假设常不成立（但分类排序往往仍可用）；连续特征高斯假设要看分布。
- **数据形态**：`X`，`(n, p)`（GaussianNB）或计数矩阵（MultinomialNB）。
- **关键调用**：

```python
from sklearn.naive_bayes import GaussianNB
GaussianNB().fit(X, y).predict_proba(X)
```

---

### 10. 分类评估（必备）

- **定位**：让分类结果可信。
- **场景**：所有分类题收尾；不均衡数据尤其重要。
- **边界**：accuracy 在不均衡数据上会骗人；阈值 0.5 不一定最优（可用约登指数选阈）。
- **数据形态**：`y_true`、`y_pred`、`y_proba`（正类概率）。
- **关键调用**：

```python
print(res.summary())                                          # CV + 测试集指标
pm.metrics.confusion_table(y_test, y_pred)                    # 混淆矩阵
fig, ax, auc = pm.roc(y_test, y_proba, save="q2_roc")         # ROC + AUC
```

## C. 聚类与降维

### 11. K-means 聚类

- **定位**：基于距离的划分聚类，最常用。
- **场景**：分群（客户/城市/样本）、图像压缩。
- **边界**：
  - 需预设 k（肘部法/轮廓系数选）；
  - 假设簇为球状且规模相近；
  - 对初始点敏感（`n_init` 多次重启）；
  - 对量纲和异常值敏感（用前必须标准化 + 排查异常）。
- **数据形态**：`X` 标准化 `(n, p)` 数值矩阵。
- **关键调用**：

```python
cl = pm.ml.kmeans(X, k=3, seed=42)          # 返回 labels/centers/metrics
print(cl.summary())
table = pm.ml.elbow(X, k_range=range(2, 11))  # 选 k：画 inertia / silhouette
pm.line(table["k"], [table["inertia"]], xlabel="k", ylabel="inertia", save="elbow")
```

---

### 12. 层次聚类

- **定位**：树状归并，不预设簇数。
- **场景**：小样本（<300）、需要树状图解释、变量聚类。
- **边界**：O(n²) 复杂度；一旦合并不可撤销；距离/连接方式（ward/complete/average）要说明。
- **数据形态**：`X` 标准化 `(n, p)`；或距离矩阵 `(n, n)`。
- **关键调用**：

```python
from scipy.cluster.hierarchy import dendrogram, fcluster, linkage
Z = linkage(Xs, method="ward")
labels = fcluster(Z, t=4, criterion="maxclust")    # 切 4 类
dendrogram(Z)                                       # 画树状图（保存后进论文）
```

---

### 13. DBSCAN（密度聚类）

- **定位**：按密度发现任意形状簇，自动识别噪声点。
- **场景**：空间数据、非球形簇、含噪声/异常。
- **边界**：`eps/min_samples` 难调（用 k-距离图）；不同密度簇难以兼顾；高维效果差。
- **数据形态**：`X` 标准化 `(n, p)`。
- **关键调用**：

```python
from sklearn.cluster import DBSCAN
labels = DBSCAN(eps=0.5, min_samples=5).fit_predict(Xs)
np.sum(labels == -1)                                # 噪声点数量
```

### 14. 主成分分析（PCA）

- **定位**：线性降维 + 去共线性。
- **场景**：指标太多、共线性严重、可视化高维数据、综合得分（客观）。
- **边界**：主成分是原变量线性组合，解释性弱；量纲不同必须标准化；对异常值敏感。
- **数据形态**：`X`，`(n, p)` 数值矩阵（标准化由本库自动做）。
- **关键调用**：

```python
pc = pm.ml.pca(pd.DataFrame(X, columns=names), n_components=3)
print(pc.summary())                                  # 方差解释率 / 累计
pc.loadings                                           # 载荷矩阵（解释主成分含义）
pc.scores                                             # 得分（可再聚类/排序）

# 累计解释率 ≥ 85% 常用于确定主成分个数
```

---

### 15. 因子分析（FA）

- **定位**：寻找潜变量（因子）解释观测变量相关性。
- **场景**：问卷/量表结构分析、指标体系内在维度探索。
- **边界**：与 PCA 不同（FA 有误差项模型）；旋转后的因子含义需人为命名；样本量 ≥ 变量数 × 10 较稳。
- **数据形态**：`X` 标准化 `(n, p)`。
- **关键调用**：

```python
from sklearn.decomposition import FactorAnalysis
fa = FactorAnalysis(n_components=3, random_state=0).fit(Xs)
fa.components_.T                                       # 因子载荷
```

---

### 16. 生存分析（选学）

- **定位**：带删失数据的时间-事件分析（寿命、故障、留存）。
- **场景**：设备寿命、用户流失、治疗后生存期。
- **边界**：需区分删失类型；比例风险假设要检验（Schoenfeld 残差）。
- **数据形态**：`T`，`(n,)` 生存时间；`E`，`(n,)` 事件指示（1=发生，0=删失）；协变量 `X`。
- **关键调用**：

```python
# 需先安装：uv add lifelines
from lifelines import KaplanMeierFitter, CoxPHFitter
KaplanMeierFitter().fit(T, E).plot()                   # KM 曲线
CoxPHFitter().fit(df[["T", "E", "x1", "x2"]], "T", "E")  # 多因素
```

---

!!! tip "分类聚类的报告规范"
    - 聚类：必须给 k 的选择依据（肘部/轮廓）、簇的画像（各簇均值对比表）、业务解释；
    - 分类：必须给混淆矩阵 + 至少两个指标（accuracy + F1/AUC）+ 交叉验证；
    - 降维：给方差解释率累计图 + 载荷表，说明主成分命名。
