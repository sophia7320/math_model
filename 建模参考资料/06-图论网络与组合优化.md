# 06 · 图论网络与组合优化

> 适用题型：网络类（交通、通信、供应链、社交传播、管网）。
> 工具：`networkx`（已装）。原则：先画图理解结构，再选算法，最后做鲁棒性分析。

## 1. 图的构建与查看

- **定位**：把表格数据变成图结构。
- **场景**：任何网络题的第一步。
- **边界**：有向/无向、带权/无权、多重边要分清；邻接矩阵适合稠密图，边列表适合稀疏图。
- **数据形态**：边表 `[(起点, 终点, 权重), ...]` 或邻接矩阵 `(n, n)`。
- **关键调用**：

```python
import networkx as nx

G = nx.Graph()                                        # 无向图；有向用 nx.DiGraph()
G.add_weighted_edges_from([("A", "B", 4.0), ("B", "C", 2.5)])   # (u, v, weight)
G.number_of_nodes(), G.number_of_edges()
list(G.neighbors("A"))
M = nx.to_numpy_array(G)                              # 邻接矩阵
```

## 2. 最短路径

- **定位**：两点间最小代价路径。
- **场景**：交通导航、配送、网络路由；也用于"网络直径/平均距离"等指标。
- **边界**：
  - Dijkstra 要求**非负权**；含负权用 Bellman-Ford；
  - 全源最短路用 Floyd（O(n³)，n<500 合适）；
  - 边权含义（时间/距离/费用）要一致。
- **数据形态**：带权图；源点/终点节点。
- **关键调用**：

```python
path = nx.dijkstra_path(G, source="A", target="Z", weight="weight")
length = nx.dijkstra_path_length(G, source="A", target="Z", weight="weight")
all_pairs = nx.floyd_warshall_numpy(G, weight="weight")           # 全源距离矩阵
nx.bellman_ford_path(G, source="A", target="Z")                   # 允许负权

# 平均路径长度 / 直径（网络效率指标）
nx.average_shortest_path_length(G)
nx.diameter(G)
```

---

## 3. 最小生成树（MST）

- **定位**：连接所有节点且总成本最小。
- **场景**：电网/管道铺设、通信骨干网、聚类前处理。
- **边界**：只适用于无向连通图；最小生成树不保证两点间路径最短（那是最短路问题）。
- **数据形态**：无向带权图。
- **关键调用**：

```python
mst = nx.minimum_spanning_tree(G, weight="weight")
mst.size(weight="weight")                             # 总权重
```

---

## 4. 最大流 / 最小割

- **定位**：容量网络上从源到汇的最大输送量。
- **场景**：运输能力、通信带宽、任务分配上限；最小割识别瓶颈。
- **边界**：容量必须非负；整数容量才有整数最大流；多源多汇需加超级源/汇。
- **数据形态**：有向图，边属性 `capacity`；源点 `s`、汇点 `t`。
- **关键调用**：

```python
G.add_edge("u", "v", capacity=10)
flow_value, flow_dict = nx.maximum_flow(G, "s", "t")
cut_value, (S, T) = nx.minimum_cut(G, "s", "t")       # 最小割 = 最大流
```

---

## 5. 最小费用流

- **定位**：在满足流量需求下总费用最小。
- **场景**：物流调运（运价不同）、带成本的供需匹配。
- **边界**：需满足供需平衡（总供给=总需求），否则先加虚拟节点；负费用边要确保无负环。
- **数据形态**：边属性 `capacity` 与 `weight`（单位费用）；节点属性 `demand`（正=需求，负=供给）。
- **关键调用**：

```python
G.add_node("s", demand=-50)                           # 供给 50
G.add_node("t", demand=50)                            # 需求 50
G.add_edge("s", "t", capacity=100, weight=3)          # 单位费用 3
cost, flow_dict = nx.network_simplex(G)               # 最小费用
```

## 6. 二分图匹配

- **定位**：两组对象一一/多对一匹配。
- **场景**：人员-岗位、论文-审稿人、供需配对；与指派问题（02 章）区别：不要求完全匹配、可有未匹配节点。
- **边界**：图必须是二分图；最大匹配 ≠ 完美匹配（存在未覆盖节点时要说明）。
- **数据形态**：`nx.Graph()` 二分结构，左右节点集标 `bipartite` 属性。
- **关键调用**：

```python
from networkx.algorithms.bipartite import maximum_matching
matching = maximum_matching(G, top_nodes=left_nodes)   # {节点: 匹配对象}
len(matching) // 2                                     # 匹配边数
```

## 7. 网络中心性（找关键节点）

- **定位**：量化节点在网络中的重要性。
- **场景**：关键城市/枢纽识别、传播源定位、风险节点评估。
- **边界**：不同中心性含义不同——度=局部连接，介数=桥梁作用，接近=到全网近，特征向量=邻居影响力；结论要指明用了哪个及理由。
- **数据形态**：图（带权可选）。
- **关键调用**：

```python
deg = nx.degree_centrality(G)                         # 度中心性
btw = nx.betweenness_centrality(G, weight="weight")   # 介数
clo = nx.closeness_centrality(G)
eig = nx.eigenvector_centrality(G, max_iter=500)
top5 = sorted(btw, key=btw.get, reverse=True)[:5]     # 介数最高的 5 个节点
```

## 8. PageRank

- **定位**：全局重要性排序（Google 的网页排序思想）。
- **场景**：影响力排序、节点重要性、传播能力。
- **边界**：对阻尼系数 α（默认 0.85）敏感度小但要说明；有向图效果最好；孤立节点需要处理。
- **数据形态**：有向图（无权也可）。
- **关键调用**：

```python
pr = nx.pagerank(G, alpha=0.85)
```

## 9. 连通性与社团发现

- **定位**：网络的分块结构。
- **场景**：城市群划分、社群识别、网络分割。
- **边界**：社团算法结果随算法不同而不同（Louvain/greedy），需给模块度与解释；无向图适用。
- **数据形态**：无向图。
- **关键调用**：

```python
from networkx.algorithms.community import greedy_modularity_communities
comps = list(greedy_modularity_communities(G))
modularity = nx.algorithms.community.modularity(G, comps)

# 连通分量
n_comp = nx.number_connected_components(G)
```

## 10. 网络鲁棒性分析（赛题高配）

- **定位**：模拟节点/边失效，评估网络韧性。
- **场景**：对抗攻击/故障传播、关键节点保护策略。
- **边界**：失效策略要说明（随机/蓄意/按中心性排序）；指标定义要一致（最大连通分量占比等）。
- **数据形态**：图 + 移除策略序列。
- **关键调用**：

```python
def largest_component_ratio(G):
    Gc = G.copy()
    comps = sorted(nx.connected_components(Gc), key=len, reverse=True)
    return len(comps[0]) / G.number_of_nodes()

# 蓄意攻击：按介数从高到低逐个移除
order = sorted(btw, key=btw.get, reverse=True)
ratios = []
Gc = G.copy()
for node in order:
    Gc.remove_node(node)
    ratios.append(largest_component_ratio(Gc))        # 画"移除比例-连通性"曲线
```

    3. 关键指标排名表；4. 若涉及流：流量分配热图。
