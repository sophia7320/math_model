# 01 · 评价决策类模型

> 适用题型：评价类（选优、排序、分级、决策）。核心链路：
> **指标体系 → 正向化 → 无量纲化 → 权重（主观/客观/组合）→ 合成得分 → 排序/分级**。

## 0. 通用预处理（所有评价模型共用）

```python
import numpy as np

# X: (n_方案, m_指标) 的 ndarray，已提取好
# direction: 长度 m 的数组，1=效益型（越大越好），-1=成本型（越小越好），0=适度型另行处理

def normalize(X, direction):
    Z = (X - X.min(0)) / (X.max(0) - X.min(0))       # min-max 到 [0,1]
    Z[:, direction < 0] = 1 - Z[:, direction < 0]    # 成本型反转
    return Z
```

- **数据形态**：`X` 行=评价对象（方案/城市/年份），列=指标；数值型、无缺失。
- **边界**：量纲不同必须无量纲化；适度型指标（如 pH、温度）用分段函数或偏离度 `1 - |x - x*| / max|x - x*|`。

## 1. AHP 层次分析法

- **定位**：主观赋权，专家两两比较构造判断矩阵。
- **场景**：指标 ≤ 9 个、缺乏客观数据、需要体现专家偏好；评价体系分层时配合权重传递。
- **边界**：
  - 一致性要求 `CR < 0.1`，否则判断自相矛盾，需返工调整；
  - 指标多时（>9）标度混乱、专家负担大；
  - 主观性强，单独使用易被质疑——建议与熵权法组合或交叉验证。
- **数据形态**：判断矩阵 `A`，形状 `(m, m)`，`a_ij` 用 1–9 标度且 `a_ij · a_ji = 1`。
- **关键调用**：

```python
import numpy as np
A = np.array([[1, 3, 5], [1/3, 1, 2], [1/5, 1/2, 1]])   # 判断矩阵 (m,m)

lam, v = np.linalg.eig(A)
w = np.real(v[:, np.argmax(lam.real)])
w = w / w.sum()                                          # 权重向量 (m,)
CI = (lam.real.max() - len(A)) / (len(A) - 1)
RI = {1: 0, 2: 0, 3: .52, 4: .89, 5: 1.12, 6: 1.26, 7: 1.36, 8: 1.41, 9: 1.46}
CR = CI / RI[len(A)]                                     # CR < 0.1 才通过
```

## 2. 熵权法（客观赋权）

- **定位**：根据指标的离散程度自动定权：数据越"乱"信息量越大，权重越高。
- **场景**：客观数据充分、不想掺主观判断；与 AHP 组合成"主客观组合赋权"。
- **边界**：
  - 对极端值敏感，指标数值需先正向化 + 非负化（`min-max` 后加小量）；
  - 无业务含义，可能出现"重要但不分散"的指标权重很低的反直觉结果；
  - 样本太少时权重不稳定。
- **数据形态**：`X`，`(n方案, m指标)`，已正向化、归一化，元素 ≥ 0（可含 0，加扰动）。
- **关键调用**：

```python
X = np.asarray(X, float) + 1e-12            # 避免 log(0)
P = X / X.sum(0)                            # 比重矩阵 (n,m)
E = -(P * np.log(P)).sum(0) / np.log(len(X))  # 信息熵 (m,)
W = (1 - E) / (1 - E).sum()                 # 熵权 (m,)
```

## 3. 变异系数法（客观赋权，极简版）

- **定位**：用 `CV = 标准差 / 均值` 度量指标差异，直接归一化当权重。
- **场景**：应急、快速估计；数据均为正值。
- **边界**：均值接近 0 时爆炸；不考虑指标相关性；严谨性弱于熵权，只适合草稿或稳健性对照。
- **数据形态**：`X`，`(n, m)`，同量纲或已标准化。
- **关键调用**：

```python
CV = X.std(0, ddof=1) / X.mean(0)
W = CV / CV.sum()
```

## 4. TOPSIS 逼近理想解排序

- **定位**：经典排序方法：离"最优解"越近、离"最劣解"越远得分越高。
- **场景**：多方案排序、指标有明确优劣方向；与熵权/AHP 搭配（**竞赛最高频组合**）。
- **边界**：
  - 必须已完成正向化，否则"理想解"无意义；
  - 对权重敏感，最好做权重灵敏度分析；
  - 只能排序，不能直接回答"谁达标"（分级要另配阈值）。
- **数据形态**：`X`，`(n, m)` 已正向化；`W`，`(m,)` 权重和=1。
- **关键调用**：

```python
Z = X / np.sqrt((X ** 2).sum(0))            # 向量归一化
Z = Z * W                                   # 加权决策矩阵
best, worst = Z.max(0), Z.min(0)
Dp = np.sqrt(((Z - best) ** 2).sum(1))      # 到最优解距离
Dn = np.sqrt(((Z - worst) ** 2).sum(1))     # 到最劣解距离
score = Dn / (Dp + Dn)                      # 相对接近度，越大越好
```

## 5. 模糊综合评价

- **定位**：把"好/一般/差"等模糊判断量化，多指标合成后定级。
- **场景**：指标含定性描述（舒适度、风险等级）、评价等级边界模糊（优/良/中/差）。
- **边界**：
  - 隶属函数选择主观（常用三角/梯形/高斯），需要说明取值依据；
  - 合成算子选择（`M(·,+)` 加权平均）会影响结果，建议给敏感性分析；
  - 等级划分标准需来自文献或题目。
- **数据形态**：`R`，`(m指标, k等级)` 隶属度矩阵（每个指标对所有等级的隶属度，列常归一）；`W`，`(m,)` 权重。
- **关键调用**：

```python
B = W @ R                                    # 综合隶属度 (k,)
# 若等级带分值（如 [95, 85, 75, 65]）：score = B @ grades
```

## 6. 灰色关联分析（GRA）

- **定位**：用"序列几何形状的接近程度"度量各方案与理想方案的关联度。
- **场景**：小样本（≥4）、数据分布未知、信息不完全；序列趋势比较（如各城市指标随理想序列的变化）。
- **边界**：
  - 分辨系数 ρ 取值（默认 0.5）主观，结果对其有一定敏感性；
  - 只能给出相对排序，不解释绝对差距；
  - 数据需先无量纲化。
- **数据形态**：`X`，`(n+1, m)`，**第 0 行为参考序列**（各指标最优值），其余为方案。
- **关键调用**：

```python
Xn = (X - X.min(0)) / (X.max(0) - X.min(0))            # 归一化
D = np.abs(Xn - Xn[0])                                  # 与参考序列的差
xi = (D.min() + 0.5 * D.max()) / (D + 0.5 * D.max())    # 关联系数，ρ=0.5
r = xi[1:].mean(1)                                      # 各方案关联度（越大越好）
```

## 7. 秩和比法（RSR）

- **定位**：把多指标排名转成"秩和比"，按概率单位分布分级。
- **场景**：多指标综合排序 + 分档（高/中/低），医学统计类评价常用。
- **边界**：只利用秩信息，损失的数值差异信息随指标数减少而放大；同分需自定义处理策略。
- **数据形态**：`X`，`(n, m)`，效益型（成本型先取负或反转）。
- **关键调用**：

```python
from scipy.stats import rankdata, norm

R = rankdata(X, axis=0)                 # 列内秩 (n,m)
RSR = R.mean(1) / len(X)                # 秩和比 (n,)
# 分级：Probit 变换后按正态分位数划档
probit = norm.ppf((RSR - 0.25) / (len(X) + 0.5)) / 3 + 2.5
```

## 8. 数据包络分析（DEA, CCR 模型）

- **定位**：多投入多产出下度量各决策单元（DMU）的相对效率。
- **场景**：效率评价（医院/学校/银行/产业园），无需预设权重与生产函数。
- **边界**：
  - 要求同质性 DMU（同类型单位）；
  - DMU 数量 ≥ 投入+产出指标数的 2–3 倍，否则大量"有效单元"；
  - 对异常值敏感；CCR 是规模报酬不变假设，规模报酬可变用 BCC。
- **数据形态**：`X`，`(n_DMU, m_投入)`；`Y`，`(n_DMU, s_产出)`，均为正值。
- **关键调用**（对每个 DMU 循环求解，得到各自效率）：

```python
import pulp

n, m, s = len(X), X.shape[1], Y.shape[1]
efficiencies = []
for k in range(n):
    prob = pulp.LpProblem(f"DEA_{k}", pulp.LpMaximize)
    u = [pulp.LpVariable(f"u_{j}", lowBound=0) for j in range(s)]   # 产出权重
    v = [pulp.LpVariable(f"v_{i}", lowBound=0) for i in range(m)]   # 投入权重
    prob += pulp.lpSum(u[j] * Y[k, j] for j in range(s))            # max 加权产出
    prob += pulp.lpSum(v[i] * X[k, i] for i in range(m)) == 1       # 加权投入归一
    for t in range(n):                                              # 所有 DMU 效率 ≤ 1
        prob += (pulp.lpSum(u[j] * Y[t, j] for j in range(s))
                 <= pulp.lpSum(v[i] * X[t, i] for i in range(m)))
    prob.solve(pulp.PULP_CBC_CMD(msg=0))
    efficiencies.append(pulp.value(prob.objective))                 # 效率值 ∈ (0,1]
```

## 9. 组合赋权（推荐写法）

- **定位**：主观权重 + 客观权重融合，兼顾业务含义与数据信息。
- **场景**：几乎所有评价赛题的稳健选择：`AHP 得 w1 + 熵权得 w2 → 组合 w`。
- **边界**：组合系数（0.5/0.5）无客观依据，需要做"权重敏感性"说明；几何平均要求权重大于 0。
- **数据形态**：两个权重向量 `(m,)`，和都为 1。
- **关键调用**：

```python
w = 0.5 * w_ahp + 0.5 * w_entropy                       # 线性组合（常用）
# 或 几何平均：w = np.sqrt(w_ahp * w_entropy); w = w / w.sum()
```

## 10. 竞赛标准组合流程（AHP-熵权-TOPSIS）

> 评价类题目的"万能主线"，建议按此组织论文：

1. 构建指标体系：分组（经济/环境/社会…），注明数据来源与方向；
2. `AHP` 得主观权重 `w1`（附判断矩阵与 CR 检验）；
3. `熵权法` 得客观权重 `w2`（附信息熵表）；
4. 组合权重 `w = 0.5w1 + 0.5w2`；
5. `TOPSIS` 排序打分 → 排名表；
6. 稳健性：换成纯熵权/纯 AHP 重算，排名变化小则结论稳健；
7. 出图：雷达图（各方案指标画像）、得分条形图、排名变化图；
8. 结果写入 `reports/RESULTS_REPORT.md`，分数保留 4 位有效数字。

!!! tip "评价类常见扣分点"
    - 指标方向（成本型/效益型）写反；
    - 权重不做归一化（和 ≠ 1）；
    - 只给排名不给得分，无法比较差距；
    - 不做灵敏度分析就下"最优"结论。
