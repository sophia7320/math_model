# 03 · 预测预报类模型

> 适用题型：预测类（产量/销量/人口/流量/浓度预报）。核心链路：
> **数据清洗 → 特征/滞后构建 → 平稳性诊断 → 模型 → 训练/验证划分 → 误差评估 → 预测区间**。
>
> 铁律：任何预测必须做**样本外验证**（留出集或滚动回测），不能只报拟合精度。
>
> 时间序列深入版（公式 / 定阶 / 诊断 / 完整代码 / 论文写法 + statsmodels 实测坑）：根目录 `时间序列模型详解.md`。

## 1. 多元线性回归（基准模型，先跑为敬）

- **定位**：最简可解释预测模型，建立基线。
- **场景**：特征与目标近似线性；需要解释各因素影响（系数显著性）。
- **边界**：多重共线性（VIF > 10）使系数不稳定；异方差影响显著性；非线性关系直接上会欠拟合。
- **数据形态**：`X`，`(n, p)` 数值特征；`y`，`(n,)` 连续目标；特征事先标准化更好。
- **关键调用**：

```python
import program as pm

model = pm.stats.ols(df, y="目标", xs=["特征1", "特征2"])   # statsmodels，完整摘要
print(model.summary())                                    # 系数、t 值、R²、F 检验

# 建模评估走 program.ml
res = pm.ml.fit_regressor("linear", X, y, test_size=0.2, cv=5, seed=42)
res.test_metrics["R2"], res.test_metrics["RMSE"]
```

## 2. 岭回归 / LASSO（正则化线性）

- **定位**：在共线性或特征多于样本时稳住系数（岭），或做变量选择（LASSO）。
- **场景**：特征多、共线性强、需要稀疏解（找出关键因子）。
- **边界**：系数有偏（岭不稀疏）；`alpha` 需交叉验证调参；标准化后再惩罚（否则尺度不公平）。
- **数据形态**：`X` 标准化后 `(n, p)`；`y` 居中。
- **关键调用**：

```python
from sklearn.linear_model import RidgeCV, LassoCV
ridge = RidgeCV(alphas=np.logspace(-3, 3, 20)).fit(Xs, y)     # 自带 CV 选 alpha
lasso = LassoCV(cv=5, random_state=0).fit(Xs, y)
lasso.coef_ != 0                                               # LASSO 的变量选择
```

## 3. 平稳性诊断与序列分解（做时序前的体检）

- **定位**：判断序列是否平稳、拆分趋势/季节/随机项。
- **场景**：任何 ARIMA/SARIMA 建模前的必做诊断。
- **边界**：ADF 检验对结构突变不敏感；分解前序列长度至少覆盖 2–3 个完整周期。
- **数据形态**：`y`，`(T,)` 等间隔序列（索引为时间）。
- **关键调用**：

```python
from statsmodels.tsa.stattools import adfuller
p_adf = adfuller(y)[1]                    # p < 0.05 → 平稳；否则差分

from statsmodels.tsa.seasonal import STL
res = STL(y, period=12).fit()             # 趋势/季节/残差
res.trend, res.seasonal, res.resid

# 差分（一阶）
dy = np.diff(y)
```

## 4. ARIMA / SARIMA

- **定位**：单变量时间序列的经典统计预测。
- **场景**：有明显自相关、无强外部因子的序列；短期预测稳定。
- **边界**：
  - 要求（差分后）平稳，非平稳序列先差分；
  - 只能捕捉线性自相关，无法利用外生变量（需要时上 ARIMAX/SARIMAX）；
  - `(p,d,q)` 定阶依赖 ACF/PACF 或 AIC 网格搜索。
- **数据形态**：`y`，`(T,)` 等间隔；缺失值需先补。
- **关键调用**：

```python
from statsmodels.tsa.arima.model import ARIMA
model = ARIMA(y, order=(1, 1, 1)).fit()
forecast = model.forecast(12)
ci = model.get_forecast(12).conf_int()        # 预测区间

# 季节性序列用 SARIMA
from statsmodels.tsa.statespace.sarimax import SARIMAX
SARIMAX(y, order=(1, 1, 1), seasonal_order=(1, 1, 1, 12)).fit().forecast(12)

# 定阶：AIC 网格
best = min(((p, d, q) for p in range(4) for d in range(2) for q in range(4)),
           key=lambda o: ARIMA(y, order=o).fit().aic)
```

## 5. 指数平滑（Holt-Winters）

- **定位**：对趋势和季节做指数加权，简单稳健。
- **场景**：短期商业预测、平滑数据；比 ARIMA 更"耐操"。
- **边界**：不适合复杂自相关结构；季节周期必须已知；对突变不敏感（滞后）。
- **数据形态**：`y`，`(T,)`；`seasonal_periods` 如月度=12、季度=4、周=7。
- **关键调用**：

```python
from statsmodels.tsa.holtwinters import ExponentialSmoothing
model = ExponentialSmoothing(y, trend="add", seasonal="add", seasonal_periods=12).fit()
forecast = model.forecast(12)
```

## 6. 灰色预测 GM(1,1)

- **定位**：小样本（≥4 个点）、信息不完全的序列预测。
- **场景**：数据稀缺（年鉴几行）、单调趋势；赛题中常用作对照模型。
- **边界**：
  - 只适合近似指数增长/衰减的序列，波动大时误差大；
  - 长期预测外推不可靠（指数发散）；
  - 必做后验差检验（C < 0.35 好，< 0.5 合格）。
- **数据形态**：`x0`，`(n,)` 非负原始序列，等间隔；先做级比检验 `λ(k) = x0(k-1)/x0(k) ∈ (e^{-2/(n+1)}, e^{2/(n+1)})`。
- **关键调用**：

```python
# x0: 原始序列 (n,)，n ≥ 4
x1 = np.cumsum(x0)                                   # 一次累加
z1 = 0.5 * (x1[1:] + x1[:-1])                        # 紧邻均值
B = np.column_stack([-z1, np.ones_like(z1)])
a, b = np.linalg.lstsq(B, x0[1:], rcond=None)[0]     # 最小二乘估参
coef = x0[0] - b / a
x1_hat = coef * np.exp(-a * np.arange(len(x0) + h + 1)) + b / a
x0_hat = np.diff(x1_hat)[: len(x0) + h]              # 还原序列，取预测段

# 精度检验：后验差比 C = S2 / S1（残差标准差 / 原始标准差）
resid = x0 - x0_hat[: len(x0)]
C = resid.std(ddof=1) / x0.std(ddof=1)
```

## 7. BP 神经网络（MLP）

- **定位**：通用非线性拟合器。
- **场景**：特征-目标关系复杂、样本量中等（几百~几千）。
- **边界**：
  - 需要标准化输入；黑箱、不可解释；
  - 小样本极易过拟合（必须有验证集 + early stopping）；
  - 调参（层数、神经元、学习率）成本高，先跑树模型对照。
- **数据形态**：`X`，`(n, p)` **标准化后**；`y`，`(n,)`（回归）或 one-hot（分类）。
- **关键调用**：

```python
from sklearn.neural_network import MLPRegressor
model = MLPRegressor(hidden_layer_sizes=(64, 32), activation="relu",
                     max_iter=3000, early_stopping=True, random_state=42)
model.fit(X_train_scaled, y_train)
y_pred = model.predict(X_test_scaled)

# program 快捷入口（自动标准化+CV）
res = pm.ml.fit_regressor("mlp", X, y, seed=42)
```

## 8. LSTM（长短期记忆网络）

- **定位**：序列深度学习模型，捕捉长期依赖。
- **场景**：长序列（>100 步）、多变量时序、复杂季节模式；数据量足够。
- **边界**：
  - 数据少于几千条时往往跑不过 ARIMA/树模型；
  - 训练慢、调参玄学；对随机种子敏感（固定 `torch.manual_seed`）；
  - 必须做滚动窗口构造样本，防止信息泄漏（未来值不能进特征）。
- **数据形态**：`x_seq`，`(batch, seq_len, n_features)` 张量；`y`，`(batch, 1)`；先做滑动窗口。
- **关键调用**：

```python
import torch
import torch.nn as nn

torch.manual_seed(42)

class LSTMForecast(nn.Module):
    def __init__(self, n_features=1, hidden=32):
        super().__init__()
        self.lstm = nn.LSTM(n_features, hidden, batch_first=True)
        self.fc = nn.Linear(hidden, 1)
    def forward(self, x):
        out, _ = self.lstm(x)
        return self.fc(out[:, -1])       # 取最后时间步

model = LSTMForecast()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
loss_fn = nn.MSELoss()
# 训练循环：pred = model(xb); loss = loss_fn(pred, yb); loss.backward(); opt.step()
```

## 9. 随机森林 / GBDT（表格数据首选）

- **定位**：集成树模型，非线性 + 特征重要性。
- **场景**：表格数据预测（销量、房价、负荷）；中等样本；想要"稳"的结果。
- **边界**：
  - 不擅长外推（树的分段常数，超出训练范围无法预测趋势）；
  - 高维稀疏数据表现一般；需要调 `n_estimators/max_depth`；
  - 特征重要性有偏（偏好高基数特征），解释时注意。
- **数据形态**：`X`，`(n, p)` 可含类别（需编码）；`y`，`(n,)`。
- **关键调用**：

```python
res = pm.ml.fit_regressor("rf", X, y, test_size=0.2, cv=5, seed=42)
res.model.feature_importances_                        # 特征重要性
table = pm.ml.compare_models(["linear", "rf", "gbr"], X, y, cv=5, seed=42)

# 时间序列预测记得用"时间切分"而不是随机划分：
# X_train = X[:T0]; X_test = X[T0:]
```

## 10. 支持向量回归（SVR）

- **定位**：小样本非线性回归，结构风险最小化。
- **场景**：样本 100~1000、目标平滑连续。
- **边界**：必须标准化；参数 `C/gamma` 敏感（网格 + CV）；大样本（>10^4）训练慢。
- **数据形态**：`X` 标准化 `(n, p)`；`y` 缩放。
- **关键调用**：

```python
from sklearn.svm import SVR
model = SVR(C=10, gamma="scale", epsilon=0.05).fit(Xs, y)
# program 快捷入口（自动标准化）
res = pm.ml.fit_regressor("svr", X, y, seed=42)
```

## 11. 马尔可夫链预测

- **定位**：状态转移预测（离散状态）。
- **场景**：市场份额、信用等级、气象状态、设备状态转移。
- **边界**：马尔可夫性（未来只依赖当前状态）需检验；状态划分主观；平稳分布存在性要验证（不可约+非周期）。
- **数据形态**：状态序列 `(T,)`；转移频数矩阵 → 概率矩阵 `P`，`(k, k)` 行和=1。
- **关键调用**：

```python
# 统计转移矩阵
P = np.zeros((k, k))
for a, b in zip(states[:-1], states[1:]):
    P[a, b] += 1
P = P / P.sum(1, keepdims=True)                       # 行归一

# 多步预测：state0 @ P^n
nxt = state0 @ P

# 平稳分布 π：解 π(P - I) = 0 且 Σπ = 1
A = P.T - np.eye(k)
A[-1] = 1
b = np.zeros(k); b[-1] = 1
pi = np.linalg.solve(A, b)
```

## 12. 组合预测（提升成绩的"合规外挂"）

- **定位**：多模型加权融合，通常优于单模型。
- **场景**：已有 2–4 个基模型（ARIMA、GM、RF、LSTM）的预测结果。
- **边界**：权重要用**验证集**估计而不是测试集（否则数据泄漏）；模型间需有一定差异（相关性太高收益小）。
- **数据形态**：各模型验证集预测 `preds`，`(n_models, n_val)`；真实值 `y_val`。
- **关键调用**：

```python
mses = np.array([np.mean((p - y_val) ** 2) for p in preds])
weights = (1 / mses) / (1 / mses).sum()               # 误差倒数权重
y_comb = (weights[:, None] * preds).sum(0)

# 想要"最优权重"时：以验证集误差为目标做小规模优化（加权和 / 最小绝对误差），
# 权重和=1 且非负，用 pm.optimize.solve_lp 或 scipy.optimize.minimize 求解。
```

## 13. 预测评估与诊断（写进论文的规范动作）

- **定位**：让"预测准不准"可量化、可对比。
- **场景**：所有预测题的收尾。
- **边界**：单一指标会被"骗"（如 MAPE 对接近 0 的真值爆炸）；至少给 MAE + RMSE + R²；时序要滚动回测。
- **数据形态**：`y_true`、`y_pred` 同形状。
- **关键调用**：

```python
m = pm.metrics.regression_metrics(y_true, y_pred)
print(pm.metrics.str_metrics(m))                      # MAE/RMSE/MAPE/R2/NSE...

pm.scatter(y_true, y_pred, xlabel="真实值", ylabel="预测值", save="pred_vs_true")
pm.hist(np.asarray(y_true) - np.asarray(y_pred), xlabel="残差", save="residual")
# 时序类再加一张"真实 vs 预测"折线（pm.line）
```

    3. 残差分布/时序；4. 多模型误差对比柱状图；5. （可选）预测区间带。
