# 07 · 通用算法与仿真

> 适用题型：随机性/不确定性场景、复杂系统仿真、策略分析。
> 这些方法经常作为"主模型的补充验证"——例如用蒙特卡洛给确定性模型加置信区间。

## 1. 蒙特卡洛模拟

- **定位**：用随机采样估计确定性方法难算的量（积分、概率、风险分布）。
- **场景**：
  - 概率/期望未知、含随机参数的模型、风险分析（VaR）、项目工期模拟；
  - 几何概率（投点法）、高维积分。
- **边界**：
  - 收敛速度 O(1/√N)：精度翻倍需要 4 倍样本；
  - 样本必须独立同分布（用固定种子保证可复现）；
  - 不能替代理论分析——结论要报置信区间与标准误。
- **数据形态**：输入变量的分布假设（正态/均匀/经验分布）；样本量 N。
- **关键调用**：

```python
rng = np.random.default_rng(42)                 # 固定种子

# 例：估计 π
pts = rng.uniform(-1, 1, (1_000_000, 2))
pi_hat = 4 * np.mean((pts ** 2).sum(1) <= 1)

# 例：风险仿真（各期销量独立正态，求利润分布）
sales = rng.normal(loc=mu, scale=sigma, size=(100_000, 12))    # (N, 12 个月)
profit = (sales * unit_margin).sum(1) - fixed_cost
np.percentile(profit, [5, 50, 95])                             # 悲观/中位/乐观
```

## 2. 元胞自动机（CA）

- **定位**：局部规则迭代产生全局复杂行为（自下而上仿真）。
- **场景**：森林火灾蔓延、交通流（NaSch）、疫情空间传播、土地利用演化、生命游戏。
- **边界**：
  - 规则是假设，必须与真实数据校准（如火灾蔓延概率）；
  - 结果随机（需多次重复统计）；
  - 网格分辨率影响结论（做网格敏感性）。
- **数据形态**：二维/一维网格状态数组；邻域规则函数。
- **关键调用**（森林火灾最小示例）：

```python
rng = np.random.default_rng(42)
grid = (rng.random((60, 60)) < 0.6).astype(int)     # 0 空地 / 1 树 / 2 燃烧

def neighbors(mask):                                # 8 邻域计数
    cnt = np.zeros_like(mask, dtype=int)
    for dx in (-1, 0, 1):
        for dy in (-1, 0, 1):
            if dx or dy:
                cnt += np.roll(np.roll(mask, dx, 0), dy, 1)
    return cnt

for step in range(50):
    burning = grid == 2
    new_burn = (grid == 1) & (neighbors(burning) > 0)   # 邻居着火则点燃
    grid[burning] = 0                                   # 烧完变空地
    grid[new_burn] = 2
    grid[(grid == 1) & (rng.random(grid.shape) < 1e-3)] = 2   # 随机自燃
# 每步统计燃烧比例 → 蔓延曲线（出图）
```

## 3. 排队论

- **定位**：服务系统的等待时间/队列长度解析计算。
- **场景**：收费站、医院、客服、服务器容量规划。
- **边界**：
  - M/M/1 假设泊松到达 + 指数服务 + 单服务台 + FIFO；
  - 系统不稳定（λ ≥ cμ）时队长发散，公式无意义；
  - 非泊松/非指数场景要用仿真（见第 9 条）。
- **数据形态**：到达率 `λ`、服务率 `μ`、服务台数 `c`。
- **关键调用**：

```python
from math import factorial

# M/M/1
rho = lam / mu                        # 利用率
Lq = rho ** 2 / (1 - rho)             # 平均排队长度
Wq = rho / (mu - lam)                 # 平均等待时间
W = 1 / (mu - lam)                    # 平均逗留时间

# M/M/c（Erlang C 求等待概率）
a = lam / mu                          # 到达强度
rho = a / c
term = a ** c / factorial(c) / (1 - rho)
P_wait = term / (sum(a ** k / factorial(k) for k in range(c)) + term)
Wq = P_wait / (c * mu - lam)          # 平均等待时间
```

## 4. 博弈论

- **定位**：多个理性决策者的策略互动。
- **场景**：定价/竞标、资源争夺、监管博弈、演化策略。
- **边界**：
  - 完全理性 + 收益共同知识假设很强；
  - 多均衡时要讨论均衡选择；
  - 连续策略空间需数值求解（最优反应迭代）；
  - **有严格支配策略的博弈没有内部混合均衡**——混合策略公式会得到分母为 0 或
    超出 [0,1] 的值，此时先做纯策略筛选（剔除劣策略）再计算。
- **数据形态**：收益矩阵（双矩阵博弈 `A, B`）或效用函数。
- **关键调用**：

```python
# 2×2 混合策略纳什均衡（行玩家以概率 p 选第一行）
# 适用前提：无严格支配策略（有支配策略时纯策略均衡，见「边界」）
# p 使列玩家两列期望收益相等：
p = (B[1, 1] - B[1, 0]) / (B[0, 0] - B[0, 1] - B[1, 0] + B[1, 1])
q = (A[1, 1] - A[0, 1]) / (A[0, 0] - A[0, 1] - A[1, 0] + A[1, 1])   # 列玩家对称计算

# 演化博弈复制动态（两策略比例 x）
x = np.array([0.5, 0.5])
for _ in range(1000):
    f = A @ x                          # 各策略适应度
    x = x + dt * x * (f - x @ f)       # 复制动态方程
    x = np.clip(x, 0, 1)
    x = x / x.sum()
```

## 5. 模糊数学

- **定位**：处理"边界不清晰"的概念（很好/较好/一般）与模糊聚类。
- **场景**：模糊综合评价（见 01 章）、模糊聚类、模糊控制。
- **边界**：
  - 隶属函数选择主观（三角/梯形/高斯），需给依据与敏感性；
  - 运算合成算子（max-min / 加权）选择影响结果；
  - 不能与概率混淆（模糊是可能性不是随机性）。
- **数据形态**：隶属度矩阵 `R`，`(n_样本, k_类别)` 或 `(m_指标, k_等级)`。
- **关键调用**：

```python
# 三角隶属函数
def trimf(x, a, b, c):
    return np.clip(np.minimum((x - a) / (b - a), (c - x) / (c - b)), 0, 1)

# 模糊 C 均值聚类（需安装：uv add scikit-fuzzy）
import skfuzzy as fuzz
cntr, u, *_ = fuzz.cluster.cmeans(X.T, c=3, m=2.0, error=1e-5, maxiter=1000, seed=42)
labels = u.argmax(0)
```

## 6. 随机过程模拟

- **定位**：时间上的随机演化（到达、扩散、状态跳变）。
- **场景**：泊松到达流、布朗运动/股价、马尔可夫状态链（见 03 章）。
- **边界**：分布假设（指数间隔/正态增量）要验证；模拟次数要足够；路径依赖问题（如障碍期权）直接模拟即可。
- **数据形态**：速率参数 `λ`、时间步 `dt`、样本路径数 `N`。
- **关键调用**：

```python
# 泊松过程事件时刻（强度 λ）
times, t = [], 0.0
while t < T:
    t += rng.exponential(1 / lam)
    times.append(t)

# 布朗运动路径
dW = rng.normal(0, np.sqrt(dt), (N_paths, n_steps))
W = np.cumsum(dW, axis=1)
```

## 7. 智能算法补充（蚁群 / 禁忌搜索）

- **定位**：针对组合优化的启发式（TSP、调度、分配）。
- **场景**：问题规模大、精确算法不可行；与前文 GA/SA/PSO 互为备选。
- **边界**：参数多（信息素挥发率、禁忌长度）、需要调参与多次重启动；务必报收敛曲线与多轮统计。
- **数据形态**：距离矩阵/成本矩阵；迭代次数；种群/邻域大小。
- **关键调用**：

```python
# 蚁群（ACO）核心：路径概率 ∝ 信息素^α × 启发式^β
probs = (tau[cur, :] ** alpha) * (eta[cur, :] ** beta)
probs[visited] = 0                                  # 已访问城市概率置零
probs = probs / probs.sum()
nxt = rng.choice(n, p=probs)                        # 轮盘赌选下一城
tau[cur, nxt] += Q / tour_length                    # 信息素更新（走完一轮后统一挥发+更新）

# 禁忌搜索（TS）核心：邻域最优中选非禁忌
tabu = set()
for it in range(max_iter):
    cands = [(delta(tour, i, j), i, j) for i, j in swap_pairs]
    delta, i, j = min(c for c in cands if (i, j) not in tabu)
    apply_swap(tour, i, j)
    tabu.add((i, j))
```

## 8. 拉丁超立方采样（灵敏度分析的采样器）

- **定位**：比纯随机更"均匀"的抽样，少量样本覆盖参数空间。
- **场景**：多参数灵敏度/不确定性分析（替代网格法）。
- **边界**：只改善覆盖均匀性，不改变模型本身；样本量仍需 ≥ 10×参数数。
- **数据形态**：参数维度 `d`、样本数 `N`、各参数分布范围。
- **关键调用**：

```python
from scipy.stats.qmc import LatinHypercube
sampler = LatinHypercube(d=3, seed=42)
U = sampler.random(100)                              # [0,1) 均匀样本 (100, 3)
X = lo + U * (hi - lo)                               # 映射到参数区间
# 对每个样本跑模型 → 得到输出分布 → 算相关系数/灵敏度指数
```

## 9. 离散事件仿真（DES）

- **定位**：按事件推进模拟流程系统（排队网络、生产调度）。
- **场景**：多服务台、优先级队列、复杂流程（医院/机场/工厂）。
- **边界**：建模工作量大；结果随机，需要多次重复；验证（与排队论/实测对比）不可少。
- **数据形态**：到达间隔分布、服务时间分布、资源数量、仿真时长。
- **关键调用**：

```python
# 方案一：手写事件循环（无依赖）
import heapq
events = [(arrival_time, "arrive", customer)]
heapq.heappush(...); t, kind, obj = heapq.heappop(events)   # 按时间推进

# 方案二：simpy（推荐，需安装：uv add simpy）
import simpy
env = simpy.Environment()
server = simpy.Resource(env, capacity=2)
def customer(env, server):
    with server.request() as req:
        yield req
        yield env.timeout(rng.exponential(service_time))
env.process(customer(env, server))
env.run(until=480)
```

## 10. 系统动力学（因果回路 + 存量流量仿真）

- **定位**：多反馈回路的系统行为仿真（经济、环境、政策）。
- **场景**：题目要求"政策模拟""反馈机制"时；变量间关系用因果图表达。
- **边界**：参数校准依赖数据或文献；正反馈易数值爆炸（有限制因子）；适合趋势判断而非精确数值。
- **数据形态**：存量初值、流量方程、参数表、时间步。
- **关键调用**：

```python
# 存量-流量方程欧拉积分（离散仿真即可，无需专门软件）
stock = stock0
history = []
for t in range(T):
    inflow = f_in(stock, params)          # 入流
    outflow = f_out(stock, params)        # 出流
    stock = stock + dt * (inflow - outflow)
    history.append(stock)
```

!!! tip "仿真类论文的三件套"
    1. **随机性说明**：分布假设来源、种子、重复次数（如 100 次取均值±标准差）；
    2. **校准**：用真实数据对齐仿真输出的关键统计量；
    3. **敏感性**：关键参数扫描，给"结论稳健"的证据。
