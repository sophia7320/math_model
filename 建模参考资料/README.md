## 使用约定

1. **代码是"关键调用行"**，默认数据已处理好：
   - 变量形状写在每个模型的「数据形态」里（如 `X: (n, m)`）；
   - 用到的 `pm` 指本工作区的 `program` 库（`import program as pm`）；
   - 需额外安装的库已用注释标注（如 `uv add lifelines`）。
2. **每个模型的「边界」是本手册的重点**——写论文时"模型适用范围"一节可直接改写；
   评审最反感"不看条件乱套模型"。
3. **固定随机种子**：凡带随机性的方法（GA/SA/PSO/蒙特卡洛/仿真），
   用 `seed=42` 且说明重复次数；本工作区一律用 `pm.init(seed=...)` 或函数 `seed=` 参数。
4. **结果入报告**：模型跑出的关键数值用 `pm.record_result(...)` 写入
   `reports/RESULTS_REPORT.md`，论文阶段只从这里取数。

## 四类赛题的标准答题骨架

```text
评价类：指标体系 → 正向化/归一化 → AHP+熵权组合赋权 → TOPSIS 排序 → 灵敏度 → 雷达/条形图
优化类：假设与变量 → 目标函数 → 约束条件 → 求解（LP/MILP/NLP）→ 可行性校验 → 灵敏度
预测类：数据清洗 → 特征/滞后 → 诊断（平稳/相关）→ 模型对比（≥2 个）→ 样本外验证 → 预测+区间
机理类：机理假设 → 方程推导 → 参数反演/求解 → 数据对比验证 → 情景分析 → 局限讨论
```
