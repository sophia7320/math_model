# 05 · 微分方程与机理建模

> 适用题型：机理分析类（传染病、种群、物理、化学动力学、人口、交通流）。
> 两条路线：**正向**（已知参数推演化）与**反向**（已知数据估参数）。
> 建模范式：机理假设 → 方程 → 求解/反演 → 与数据对齐 → 预测/情景分析。

## 1. 常微分方程初值问题（ODE）

- **定位**：连续时间动力系统的标准建模工具。
- **场景**：只要状态随时间连续变化且变化率有表达式，就用它。
- **边界**：
  - 需要明确的状态变量与闭合的动力学方程（不能有未定义项）；
  - 求解器有精度与刚性之分（RK45 通用，刚性用 BDF/LSODA）；
  - 模型函数签名必须是 `f(t, y, *params)`。
- **数据形态**：`y0`，`(n_states,)` 初值；`t_span`，`(t0, t1)`；`params`，参数元组；`t_eval`，输出时间网格 `(n_t,)`。
- **关键调用**：

```python
import numpy as np
import program as pm

def model(t, y, k1, k2):                  # 函数签名固定为 f(t, y, *params)
    x, z = y
    return [-k1 * x, k1 * x - k2 * z]

sol = pm.ode.solve_ivp_model(model, y0=[1.0, 0.0], t_span=(0, 50),
                             params=(0.3, 0.1), t_eval=np.linspace(0, 50, 201))
sol.y                                     # 形状 (n_states, n_t)
```

## 2. 参数反演（用数据估模型参数）

- **定位**：把"未知参数"变成优化问题：最小化模拟值与观测值的偏差。
- **场景**：题目给了数据，但参数未知（传染病 β/γ、反应速率、传热系数）。
- **边界**：
  - 参数不可辨识（不同参数组合产生相同输出）是最常见的坑——做敏感性分析；
  - 初值敏感：多组初值对比；
  - 观测变量与模型变量的对应关系必须一一说清。
- **数据形态**：`t_data` 单调递增 `(n_t,)`；`y_data`，`(n_t,)` 或 `(n_t, n_vars)`；`p0` 初值；`bounds` 物理上下界。
- **关键调用**：

```python
fit = pm.ode.fit_ode_params(
    model, y0=[1.0, 0.0], t_data=t, y_data=obs,
    p0=[0.2, 0.05], bounds=([0, 0], [2, 1]), param_names=["k1", "k2"],
)
fit.summary()                             # RMSE / R² / 参数值
y_sim = fit.simulate(t)                   # 用最优参数重放

# 通用曲线拟合场景（无 ODE）用：pm.fitting.fit_curve(f, x, y, p0, bounds, names)
```

## 3. 传染病模型（SIR / SEIR）

- **定位**：仓室模型的代表，疫情/谣言/信息传播。
- **场景**：有传播数据、需要预测峰值/拐点/最终规模；评估隔离等措施效果。
- **边界**：
  - 均匀混合假设（人群接触完全随机），小规模/结构强的人群要上网络模型；
  - 参数时变（政策变化）时需分段或引入干预函数；
  - 基本再生数 `R0 = β/γ` 决定疫情走向（R0>1 扩散）。
- **数据形态**：累计确诊/现存感染序列 `(T,)`；人口总数 `N`；初值常取 `(N-1, 1, 0)`。
- **关键调用**：

```python
def sir(t, y, beta, gamma):
    S, I, R = y
    return [-beta * S * I / N, beta * S * I / N - gamma * I, gamma * I]

sol = pm.ode.solve_ivp_model(sir, [N - 1, 1, 0], (0, 120), params=(0.4, 0.1), t_eval=t)
R0 = 0.4 / 0.1                              # 基本再生数

# SEIR：加潜伏期 E 仓室
def seir(t, y, beta, sigma, gamma):
    S, E, I, R = y
    return [-beta*S*I/N, beta*S*I/N - sigma*E, sigma*E - gamma*I, gamma*I]
```

## 4. 种群增长（Logistic）

- **定位**：资源受限下的 S 形增长。
- **场景**：人口、市场饱和、生物种群、产品扩散（Bass 模型亲戚）。
- **边界**：环境容量 K 需估计（或作为参数拟合）；突变/政策会破坏曲线；多物种竞争要扩展。
- **数据形态**：时间序列 `(T,)`（非负）；可先差分或直接拟合解析解。
- **关键调用**：

```python
def logistic(t, y, r, K):
    return r * y * (1 - y / K)

sol = pm.ode.solve_ivp_model(logistic, [y0], (t0, t1), params=(0.5, 1000), t_eval=t)

# 或直接拟合解析解：y(t) = K / (1 + exp(-r(t - t0)))
def logistic_closed(x, K, r, x0):
    return K / (1 + np.exp(-r * (x - x0)))
fit = pm.fitting.fit_curve(logistic_closed, t, y, p0=[1000, 0.5, 20], names=["K", "r", "t0"])
```

## 5. 竞争 / 捕食模型（Lotka-Volterra）

- **定位**：两物种相互作用的经典动力学。
- **场景**：生态竞争、市场竞争（类比）、两种资源争夺。
- **边界**：无饱和项的经典 LV 会出现中性循环（对参数极敏感），实际需加 Logistic 阻尼；参数辨识需要充足数据。
- **数据形态**：两物种时间序列 `(T, 2)`。
- **关键调用**：

```python
def lv(t, z, a, b, c, d):
    x, y = z
    return [a * x - b * x * y, -c * y + d * x * y]     # 捕食者-食饵

fit = pm.ode.fit_ode_params(lv, [10, 5], t, obs2, p0=[1, 0.1, 1, 0.1],
                            bounds=([0]*4, [5]*4), param_names=["a", "b", "c", "d"])
```

## 6. 房室模型（PK/PD、物质平衡）

- **定位**：按"区室"划分的物质交换模型（药代、碳循环、经济流）。
- **场景**：药物浓度曲线、污染物迁移、多环节库存。
- **边界**：一室模型假设瞬时混合；注意单位统一（mg/L、h）；口服给药是一室+吸收室（双室）。
- **数据形态**：血药浓度 `(T,)`；给药时间点与剂量。
- **关键调用**：

```python
def one_comp_oral(t, y, ka, ke, V):
    A_gut, A_cent = y
    return [-ka * A_gut, ka * A_gut - ke * A_cent]      # 浓度 = A_cent / V
```

## 7. 差分方程（离散动力学）

- **定位**：按代/按周期更新（昆虫世代、离散库存、迭代系统）。
- **场景**：题目给"每年/每代"数据；递推关系明确。
- **边界**：与 ODE 不同，差分方程可以混沌（Logistic 映射）；稳定性分析要看特征根。
- **数据形态**：初值 + 递推函数。
- **关键调用**：

```python
x = np.empty(T)
x[0] = x0
for t in range(T - 1):
    x[t + 1] = f(x[t])                      # 一阶差分；多变量就换成数组状态

# 线性差分方程求通项（解析）：
import sympy as sp
n = sp.symbols("n")
sp.rsolve(sp.Function("a")(n + 1) - sp.Rational(1, 2) * sp.Function("a")(n) - 1, sp.Function("a")(n))
```

## 8. 偏微分方程（热传导 / 扩散 / 波动）有限差分

- **定位**：空间 + 时间的问题（温度场、浓度场、污染物扩散、波动）。
- **场景**：题目涉及"一维棒/二维板"的分布演化；边界条件明确。
- **边界**：
  - 显式差分有稳定性条件（`r = α·dt/dx² ≤ 0.5`），违约会数值爆炸；
  - 隐式格式（Crank-Nicolson）无条件稳定但要解线性方程组；
  - 边界条件（Dirichlet/Neumann）必须翻译正确。
- **数据形态**：初始场 `u0`，`(nx,)`；边界值；网格 `dx, dt`；扩散系数 `α`。
- **关键调用**：

```python
# 一维热传导 u_t = α u_xx 显式格式
u = u0.copy()
r = alpha * dt / dx**2                        # 稳定性要求 r ≤ 0.5
for _ in range(Nt):
    u[1:-1] = u[1:-1] + r * (u[2:] - 2 * u[1:-1] + u[:-2])
    u[0], u[-1] = left_bc, right_bc           # 边界条件
# 二维：u[1:-1,1:-1] += r*(上下左右四邻平均 - 中心)
```

## 9. 两点边值问题（BVP）

- **定位**：边界条件给在两端（而非初值）。
- **场景**：梁弯曲（Euler-Bernoulli）、稳态热传导、平衡态问题。
- **边界**：存在性与唯一性依问题而定；需给出合适的初始网格猜测；强非线性时收敛难。
- **数据形态**：`ode(x, y)`，`bc(ya, yb)`，初始网格 `x` 与猜测解 `y_guess`。
- **关键调用**：

```python
from scipy.integrate import solve_bvp

def ode(x, y):
    return np.vstack([y[1], -np.abs(y[0])])

def bc(ya, yb):
    return np.array([ya[0], yb[0] - 1])

sol = solve_bvp(ode, bc, x=np.linspace(0, 1, 20), y=np.zeros((2, 20)))
sol.sol(x_plot)                                # 可调用对象取任意点
```

## 10. 机理建模通用流程（论文骨架）

1. **机理假设**：写出定律（守恒/增长/反应/传导），列出假设清单（每条可验证）；
2. **变量定义**：状态变量、参数、单位表（论文必备符号表）；
3. **方程建立**：由守恒律/速率假设推导微分方程；
4. **无量纲化**（可选但加分）：减少参数、暴露特征尺度；
5. **求解/反演**：`pm.ode` 求解或拟合；
6. **模型验证**：与数据对比（RMSE/R²）、残差检查；
7. **情景/灵敏度**：关键参数 ±20% 的预测变化；
8. **结论与局限**：假设的适用边界要写清楚。

!!! tip "机理类的加分项"
    - 符号表 + 单位；- 参数敏感性热图/蛛网图；- 模型与数据对比图（必做）；
    - 说明"为什么选这个模型而不是另一个"（对照实验）。
