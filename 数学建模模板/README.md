# 2026 CUMCM 论文最终推荐排版版

## 编译

- 主文件：`main.tex`
- 编译器：**XeLaTeX**
- 建议连续编译两次，或直接使用 `latexmk -xelatex main.tex`
- 不要单独移动或遗漏 `cumcmthesis.cls`、`cumcm_official_final.sty` 与 `figures/`

## 版式原则

本版以官方兼容结构为基础，采用往年优秀数学建模论文常见的克制黑白学术风格：

- A4，四边页边距 25 mm；
- 电子版第一页为摘要专用页，页码从 1 开始；
- 不设目录、页眉和身份信息；
- 主标题与副标题分层但全部黑色；
- 一级标题居中，二三级标题左对齐；
- 三线表、黑色图表题注、居中页码；
- “本问结论”使用行内加粗，不使用彩色框；
- 不依赖 `xurl`、`mathtools`、`makecell`。

## 提交前必须核对

排版工程不等于完整参赛支撑材料。正式提交前，须按实际情况补充可运行源程序、数据账本、中间结果、运行说明及 `AI工具使用详情.pdf`，并确保论文附录中的文件列表与支撑材料压缩包完全一致。
