## 2. 分布结构 → 参考值（`q2e_structure.py`）

报童临界比 = 1 − 1/5 = **0.8**（买多损失 p、缺电损失 5p）→ 最优裕度 = 净需求残差
e = 实际净需求 − 预测净需求 的 0.8 分位数。官方 W=7 权重下实测：

| 参考量 | 数值 | 用途 |
| --- | --- | --- |
| e 均值（白天）/kW | −168.7（已偏保守） | 说明权重标定已吸收部分偏差 |
| e 标准差（白天）/kW | 568.5 | 裕度尺度的量级 |
| q80 裕度：全局 / 白天 /kW | 175 / 238 | 光伏折扣 m 的参考 |
| q80 裕度：逐时段 / 逐小时 / 逐月 /kW | 54~533 / 87~504 / 85~433 | 形状式裕度参考 |
| 比例式 ρ_ref = q80(e/P̂ \| 白天) | 0.056 | P̂(1−ρ) 参考 |
| κ_ref = 1 + q80(e/L̂) | **1.039 ~ 1.042** | 负荷抬升参考 |
| 日度偏差 AR(1) / 半衰期 | 0.51 / 1.0 天（白天 0.62 天） | W 与 EWMA 时间尺度 |
| 光伏 d−1 权重 AR(1) / 半衰期 | 0.76 / 2.6 天 | 权重记忆 |
| 日费用均值 / P95 / CVaR95 /元 | 4.39e4 / 7.16e4 / 8.85e4 | 风险厌恶 λ 的尾部依据 |
| 尾部溢价 (P95−均值)/均值 | 0.63 | 风险定价 |
| 有紧急购电天数占比 | 82.3% | 问题的普遍性 |

## 4. 解释：为什么是 κ，为什么 1.02 < κ_ref

1. **裕度应该覆盖全部时段**：残差 q80 在夜间/傍晚也有 54~100 kW（负荷误差），
   而光伏折扣只在白天生效；κ 以"负荷比例"形式把裕度铺到所有时段，故占优。
2. **κ*≈1.02 低于分布参考 κ_ref≈1.04**：报童最优是"单时段、无储能"的结果；
   LP 的储能套利与日循环会把一部分保守购电在日内重新利用，有效最优裕度低于
   纯分位数参考。分布给出的是**上界参考**，结构优化把它向下修正——两者相差
   0.5%~2%，同量级，逻辑闭合。
3. 总裕度自洽：κ=1.02 + m=50 的平均附加购电 ≈ 2%·L̂ + 50 kW，
   与全局 q80=175 kW（白天 238 kW）同量级。

## 5. 部署选项

| 方案 | 总费用/万元 | 相对官方 | 特点 |
| --- | --- | --- | --- |
| A. 现行官方（W=7） | 1467.4 | — | 现状 |

论文写法建议：把 A→B 的差异写成"**决策聚焦预测（decision-focused）**"：
精度最优 ≠ 费用最优；参考值来自残差分布（报修 q80），结构修正由 LP 完成。
